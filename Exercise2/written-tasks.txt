## a)
- GL_TRIANGLES
  - each 3 vertices describe a triangle
- GL_TRIANGLES_STRIP
  - first 3 vertices describe the first triangle
  - every following verticy build a triangle with the previous 2 vertices
- GL_TRIANGLES_FAN
  - first 3 vertices define first triangle
  - every following verticy constructs a triangle with the first point (p0) and the last point (fan around p0)
